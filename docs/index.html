02 / METHOD

Measure the answer.
Keep the evidence.

SVEA uses transparent scoring wherever possible and makes every comparison carry its protocol.

  1. 01
    Profile, don’t flatten

    Domain, task, coverage, weakest slice and uncertainty stay visible.

  2. 02
    Stress the capability

    Paired variants isolate distractors, strict formats and absent evidence.

  3. 03
    Prefer deterministic checks

    Exact, numeric, JSON and constraints run locally without a judge.

  4. 04
    Name the judge

    Open answers remain missing until a pinned judge is configured.

  5. 05
    Preserve provenance

    Revision, prompt, decoding, raw answer and latency travel together.

03 / RUN

One suite. Your endpoint.

The dependency-free core talks to hosted APIs, Ollama's native chat endpoint and local OpenAI-compatible servers. Transformers is an optional direct backend.

export OPENAI_API_KEY="…"
svea run \
  --backend openai-compatible \
  --base-url https://api.openai.com/v1 \
  --model YOUR_MODEL_ID \
  --revision PINNED_VERSION \
  --output runs/model-api.json
svea run \
  --backend ollama \
  --model gemma3:12b \
  --revision OLLAMA_MODEL_DIGEST \
  --output runs/gemma3-12b.json
python3 -m pip install -e '.[local]'
svea run \
  --backend huggingface \
  --model /path/to/checkpoint \
  --revision CHECKPOINT_SHA \
  --output runs/model-hf.json
↻ Resumable after every item ⌁ API keys never enter artifacts ◇ Raw answers retained
